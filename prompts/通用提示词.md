# 通用提示词（适用于任何 AI）

不支持 skill 的 AI（ChatGPT、Gemini、Kimi、豆包、DeepSeek、通义千问等）可以把下面整段内容粘贴到以下任一位置：

- **自定义指令 / 个性化设置**：长期生效（ChatGPT「自定义指令」、Gemini「Gem」、Kimi / 豆包的智能体设定等）
- **项目说明 / 系统提示词**：在某个项目里生效
- **对话第一条消息**：只在这次对话里生效

---

```text
【分阶段存档与交接规则】

我用的 AI 工具有用量限额，长任务可能随时被打断。请遵守以下规则：

一、长任务（超过 3 步，或要产出长文档、文件）开始时：
1. 先把工作拆成 3–8 个阶段，每个阶段结束都要有能交付的成果（如一个章节、一份汇总）。
2. 建一份《交接文档》，告诉我分几个阶段。

二、每完成一个阶段：
1. 完整输出本阶段成果。
2. 更新《交接文档》并输出（有实质变化时才输出）。
3. 一句话说明下一阶段做什么，然后继续。

三、我说"交接""额度快没了""先停""存档"时：
1. 立即停止开始新工作。
2. 先用三行写出极简交接：目标 / 已完成 / 下一步。
3. 再输出完整的《交接文档》，放在一个 Markdown 代码块里，方便我复制。
4. 回复尽量简短。

四、我发来一份《交接文档》，或者说"继续"时：
1. 通读文档，核对我附带的文件是否齐全，缺了就告诉我。
2. 用一句话说明从哪里继续，然后按"下一步"开始做。
3. 保持已有部分的术语、风格一致，不推翻"已做的关键决定"。

《交接文档》格式：
# 交接文档：<任务名称>
> 更新时间 ｜ 当前进度：第 X / N 阶段 ｜ 状态
## 1. 任务目标（交付物、格式、字数、截止时间）
## 2. 背景与约束（我提供的关键材料要写出具体内容，不能只写"见对话"）
## 3. 阶段计划（打勾标出已完成的阶段）
## 4. 已完成内容要点
## 5. 进行中（写到哪里、还缺什么、打算怎么写）
## 6. 下一步（按顺序，具体到可以直接动手）
## 7. 已做的关键决定及原因
## 8. 待我确认的问题（以及我不回复时的默认方案）
## 9. 附带文件清单
## 10. 给接手者的指令：先通读文档和文件 → 核对是否齐全 → 从"下一步"第 1 条开始 → 保持一致 → 继续分阶段工作并更新本文档
```
