# checkpoint-handoff：分阶段存档与交接

让 AI 在做长任务时**边做边存档**，额度快用完时**一声"交接"就收尾**，生成一份**任何 AI 都能直接接手**的交接文档；额度刷新后从断点继续。

适合写基金申请书、长篇报告、多章节文稿、大量文献检索这类一次做不完的工作。

## 为什么需要它

- AI 工具大多有用量限额（如五小时会话额度），长任务做到一半很容易被打断。
- AI 在对话里**通常看不到你还剩多少额度**，没法等"快没了"再自动存档。
- 换个 AI 或新开一个对话时，之前的上下文全都没了。

解决办法有两道保险：
1. **边做边存**：每完成一个阶段，就交付成果并更新交接文档。任何时候被打断，你手里都有最近一个阶段的成果。
2. **一声令下就收尾**：你一说"交接"，AI 立即停下新工作，先输出三行极简交接，再输出完整交接文档。

## Codex 额度感知版（可选）

新增独立 skill：[`quota-handoff`](skills/quota-handoff/SKILL.md)。

- 在已加载 skill 的任务执行过程中检查实际额度，短周期剩余 **≤8%** 时保存交接。
- 支持时使用当前聊天的 heartbeat 登记恢复检查；刷新后重新核验额度，从下一步继续。
- 交接包含已完成内容、验证证据、文件路径、在途操作和剩余任务；用户叫停或任务完成后停用恢复安排。

将 [`skills/quota-handoff/`](skills/quota-handoff/) 整个目录放入 Codex 的个人 skills 目录，在聊天中输入：**使用 `$quota-handoff` 处理当前任务。**

此版本依赖可用的 `get_usage_limits` 和调度工具。安装 skill 不会启动常驻监控；单次长调用可能跨过8%阈值。额度窗口以实际返回值为准，不假定每整点刷新。没有对应工具时会保存交接并明确提示手动恢复。真实跨额度窗口无人值守续跑尚未验证。

下文关于手动查看额度和喊“交接”的说明适用于通用版。

## 安装与使用

### Claude（claude.ai 网页版 / 桌面版 / 手机版）
把整个 `checkpoint-handoff` 文件夹打成 zip，在 Claude 设置的技能（Skills）管理处上传；或者在对话里直接让 Claude 帮你保存。

### Claude Code
```bash
git clone https://github.com/CHW8225/checkpoint-handoff.git ~/.claude/skills/checkpoint-handoff
```

### 其他支持 SKILL.md 格式的 AI 工具
把本文件夹放到该工具指定的 skills 目录下即可（具体位置见各工具的文档）。

### ChatGPT、Gemini、Kimi、豆包、DeepSeek 等
打开 [`prompts/通用提示词.md`](prompts/通用提示词.md)，把代码块里的内容粘贴到：
- **自定义指令 / Gem / 智能体设定**：长期生效
- **项目说明**：在某个项目里生效
- **对话第一条消息**：只在这次对话里生效

### 编程类 AI（Cursor、Codex、Copilot 等）
把 `prompts/通用提示词.md` 的内容复制进项目根目录的 `AGENTS.md`（或该工具的规则文件，如 `.cursorrules`）。

## 日常怎么用

| 你说 | AI 会做什么 |
|---|---|
| （正常布置一个长任务） | 自动拆成 3–8 个阶段，每完成一个阶段就交付成果和交接文档 |
| **交接** / 额度快没了 / 先停 / 存档 | 立即停下，先给三行极简交接，再给完整交接文档，并问你后续怎么安排 |
| **省额度模式** | 跳过可选的润色和扩展，只做主线 |
| **继续** / 额度刷新了 | 读取交接文档，核对文件，从"下一步"接着做 |

### 推荐流程
1. 在设置的用量页面留意额度。剩 10%～15% 时发"交接"。
2. 选择后续怎么做：
   - **等额度刷新**：告诉 AI 重置时间。支持定时功能的平台（如 Claude）可以到点自动继续；不支持的话，到时发"继续"即可。
   - **换个 AI 接着做**：把交接文档和成果文件发给对方，再附上 [`prompts/接手开场白.md`](prompts/接手开场白.md) 里的那段话。

## 局限

- AI 看不到你的剩余额度，"交接"需要你来喊。如果额度在你喊之前就用完了，你手里仍然有上一个阶段的成果和交接文档，最多损失一个阶段的进度——所以阶段切得越小越安全。
- 交接文档的质量取决于 AI 是否把关键信息写进去。接手前可以快速扫一眼"背景与约束"和"下一步"两节。
